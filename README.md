Natural language data analysis agent, a data analysis assistant built for business users, supports uploading CSV files or connecting to databases, allowing data queries, statistical analysis, and chart generation through natural language questions. The system converts user questions into SQL, executes them in a read-only environment, and returns analysis conclusions, visual charts, query statements, and data references. It supports follow-up questions, exception alerts, and SQL security checks, helping users complete daily data analysis more quickly.
